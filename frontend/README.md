# FIXIT PWA

Frontend React conectado a los microservicios de usuarios, progreso y partidas.

## Ejecutar

1. Copia `.env.example` como `.env`.
2. Ejecuta `npm install`.
3. Asegúrate de iniciar los tres servicios del backend.
4. Ejecuta `npm run dev` y abre `http://localhost:5173`.

Puedes registrar una cuenta nueva o probar con `jugador1@fixit.com` y contraseña `Fixit123` después de ejecutar `npm run seed` en `user-service`.
